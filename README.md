# InterpJud Oral

Entrenador personal para el examen oral del Concurso de Intérpretes Judiciales (RD, 2026), español ↔ inglés.

- Consecutiva (diálogos de audiencia), simultánea, traducción a la vista y simulacro completo.
- Graba tu voz, transcribe, mide latencia, pausas, ritmo y claridad.
- Evaluación con Claude según los 10 criterios del oral (requiere tu propia API key, guardada solo en tu dispositivo).
- Drills de números/nombres/fechas y terminología.

Funciona en Chrome/Edge (PC y Android) y Safari (iPhone). Se instala como app desde el navegador.
